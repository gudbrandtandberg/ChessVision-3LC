How this works — sample → predict → review → commit
  1. Sample — draw a fresh, diverse set of candidate boards from the upload pool into a new batch. Excludes anything already used for training or another test split, so there's no data leakage.
  2. Predict — run the ChessVision model to draft a FEN for each candidate (in both orientations). These are guesses to speed you up, not ground truth.
  3. Review — for each board, compare the raw photo to the predicted position and confirm it: A accept · F flipped · E edit · X reject (not a usable board) · ←→ browse. Decide by labelability, not difficulty — keep easy boards too, and don't cherry-pick the model's mistakes, or the test set becomes biased.
  4. Commit → 3LC — write the confirmed batch as a 3LC table and rebuild the joined test-all tip that evaluation runs against.

New batch → type a name, Sample, then Predict. Then pick it under Review / commit and go. Existing batch → just select and Review (or Commit).
